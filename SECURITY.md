# Security

## Reporting a vulnerability

Please report security issues privately, not in a public issue: open
[a private advisory](https://github.com/coltonkirsten/a12s/security/advisories/new) on this repository.
Include what you found, how to reproduce it, and the a12s version (`a12s version`).

You should get a reply within a few days. Fixes ship in the next release and are listed in the
[CHANGELOG](CHANGELOG.md).

## Supported versions

a12s is pre-1.0. Only the latest release gets security fixes.

## Scope

How a12s isolates agents, and what it does not protect against, is written down in [docs/security.md](docs/security.md).
A way around a guarantee stated there is a vulnerability.
